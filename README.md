**데이터로 금융 시장의 흐름을 읽는 분석가**를 꿈꾸고 있어요.

주가와 환율처럼 매일 달라지는 숫자 뒤에 어떤 패턴이 숨어 있는지 궁금해서 데이터 분석을 공부하기 시작했습니다.
지금은 Python과 통계의 기초를 다지면서, PostgreSQL과 Tableau로 데이터를 다루고 보여주는 방법을 익히고 있어요.
